This study analyzed international tourism data using the advanced Partial Least Squares Regression model to identify the post-pandemic new pattern of key determinants of international tourist arrivals.

The analysis scripts are organized sequentially and include detailed comments and instructions at each step.

To reproduce the analysis:

1. Install the required dependencies listed in `requirements.txt`.
2. Place the input data in the designated data directory.
3. Run the scripts in the order indicated by their filenames.
4. Follow the comments and parameter instructions provided within each script.
5. Generated results and figures will be saved to the corresponding output directories.
